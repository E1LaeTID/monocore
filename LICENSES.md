# Périmètre des licences

- Le code et la documentation du prototype Monocore suivent le périmètre de la licence MIT existante dans `monocore/LICENSE`.
- Les SVG fournis, logos, noms et contenus de catalogue tiers sont exclus de cette licence existante. Leur présence dans une archive de travail ne définit pas une licence publique de redistribution.
- Le service `ordia-room` fourni n’avait pas de fichier de licence propre. Cette livraison ne lui impose pas une licence générale. Son auteur doit définir ce périmètre avant de présenter l’ensemble comme intégralement open source.
- Les dépendances conservent leurs licences respectives.

Le contrôle du catalogue officiel et des publications est une règle de gouvernance distincte des droits sur le code. Aucun mécanisme ne peut empêcher tous les forks d’un code publié sous licence libre.
